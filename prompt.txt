# Task Dispatcher — Prompt Reference

## Coding Task Dispatch
When dispatching a coding task (type === "coding"), the dispatcher:
1. Attempts factory pipeline first (Dante ID)
2. Falls back to agent dispatch if factory fails
3. Includes a `## Coding Task` section telling the agent to read `skills/coding-task/SKILL.md`
4. The coding-task skill guides the agent through: parse → git setup → clone/pull → branch → code → build → commit → PR → status update

## Skill Trigger
The dispatcher injects this section for coding tasks:
```
## Coding Task
**Use the coding-task skill for this work.** Read `skills/coding-task/SKILL.md` and follow it step by step.
```

All worker agents (neo-worker, ifra-worker, beta-worker, and worker-template-based agents)
have the coding-task skill pre-installed in their workspace at `skills/coding-task/SKILL.md`.

## Task Types
- `coding` → coding-task skill (clone, branch, PR workflow)
- `ops` → direct execution (kubectl, curl, etc.)
- `review` → code review (read PR, comment)
- `qa` → QA testing (verify task results)
- `research` → web search, analysis
- `general` → flexible

## Status Flow
todo → assigned → in_progress → qa_testing → completed → deployed
                                             → failed (on error)
