# Task Dispatcher — Prompt Reference

This file documents the dispatch prompt structure used by the task dispatcher.

## Dispatch Flow

1. Task enters `assigned` status in Supabase
2. Dispatcher builds the dispatch message with:
   - JSON task payload (task_id, title, description, type, priority, etc.)
   - Context block (institutional memory: previous results, failed tasks, online agents)
   - Coding task section (if type=coding) — triggers the coding-task skill
   - Status update commands (curl for success/failure)
3. Message is POSTed to the agent's /hooks/agent endpoint

## Coding Task Skill Trigger

For `type: "coding"` tasks, the dispatcher injects a `## Coding Task` section that instructs
the worker agent to read `skills/coding-task/SKILL.md` and follow it step by step.

The skill covers: git setup, repo prep, branching, building, testing, PR creation, and status updates.
